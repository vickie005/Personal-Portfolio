# Portfolio V2

A modern full-stack developer portfolio built with React, TypeScript, NestJS, and PostgreSQL.

## 🚀 Overview

This portfolio is more than a personal website—it's a production-style full-stack application designed to showcase my technical skills, projects, and experience.

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- TanStack Query
- Framer Motion

### Backend
- NestJS
- TypeScript
- PostgreSQL
- TypeORM
- JWT Authentication
- Swagger

## ✨ Planned Features

- Responsive modern UI
- Dynamic project showcase
- Admin dashboard
- Blog management system
- Contact form with backend API
- Authentication
- GitHub integration
- AI-powered portfolio assistant
- Dark/Light mode
- Animations and smooth transitions
